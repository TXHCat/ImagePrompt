Privacy

Last updated: May 21, 2026

ImagePrompt analyzes only images you choose. The extension stores local settings and prompt history in Chrome storage on your browser profile.

Data sent for analysis

When you run analysis, ImagePrompt sends the selected image, page URL, alt text, dimensions, and prompt instructions to the Base URL you configure.

Local data

  • API settings are stored in Chrome storage.
  • Prompt history is stored locally in Chrome storage.
  • Image analysis is sent only to the Base URL you configure.
